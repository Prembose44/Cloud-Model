PRACTICAL: HADOOP WORD COUNT — STEPS BASED ON labs 2.0.txt

Run these commands in Ubuntu/Linux terminal, not Windows CMD.

1. Install Java and SSH
sudo apt update
sudo apt install -y openjdk-11-jdk ssh
java -version

2. Download Hadoop 3.3.6
cd ~
wget https://dlcdn.apache.org/hadoop/common/hadoop-3.3.6/hadoop-3.3.6.tar.gz
tar -xzf hadoop-3.3.6.tar.gz
mv hadoop-3.3.6 hadoop

If Hadoop is already installed, skip the download and rename commands.

3. Find Java's actual path
dirname $(dirname $(readlink -f $(which java)))

4. Configure environment variables
Open the shell configuration:
gedit ~/.bashrc

Add these lines. If the Java path printed in step 3 differs, use the actual path:
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64
export HADOOP_HOME=$HOME/hadoop
export HADOOP_MAPRED_HOME=$HADOOP_HOME
export HADOOP_HDFS_HOME=$HADOOP_HOME
export PATH=$HADOOP_HOME/bin:$HADOOP_HOME/sbin:$PATH

Save and run:
source ~/.bashrc
hadoop version

Note: The source TXT has `HADOOP_HOME=HADOOP_HOME` and an incomplete PATH expression. The `$HOME` and `$PATH` expansions above correct those shell-variable typos.

5. Configure Hadoop files
cd ~/hadoop/etc/hadoop

A. Open hadoop-env.sh:
gedit hadoop-env.sh
Set:
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64
Use your actual Java path if different.

B. Edit core-site.xml:
gedit core-site.xml
Inside its existing <configuration> tags, add:
<property>
    <name>fs.defaultFS</name>
    <value>hdfs://localhost:9000</value>
</property>

C. Edit hdfs-site.xml:
gedit hdfs-site.xml
Inside <configuration>, add:
<property>
    <name>dfs.replication</name>
    <value>3</value>
</property>
<property>
    <name>dfs.name.dir</name>
    <value>/home/YOUR_USERNAME/hadoop/data/namenode</value>
</property>
<property>
    <name>dfs.data.dir</name>
    <value>/home/YOUR_USERNAME/hadoop/data/datanode</value>
</property>
Replace YOUR_USERNAME with the output of:
whoami

D. Edit mapred-site.xml:
gedit mapred-site.xml
Inside <configuration>, add:
<property>
    <name>mapreduce.framework.name</name>
    <value>yarn</value>
</property>

E. Edit yarn-site.xml:
gedit yarn-site.xml
Inside <configuration>, add:
<property>
    <name>yarn.nodemanager.aux-services</name>
    <value>mapreduce_shuffle</value>
</property>
<property>
    <name>yarn.nodemanager.auxservices.mapreduce.shuffle.class</name>
    <value>org.apache.hadoop.mapred.ShuffleHandler</value>
</property>

Preserve each file's existing <configuration> and </configuration> tags. Do not paste a second outer configuration block.

6. Create the data directories
cd ~/hadoop
mkdir -p data/namenode data/datanode

7. Configure SSH
ssh-keygen -t rsa
Press Enter through the prompts to accept defaults.
cat ~/.ssh/id_rsa.pub >> ~/.ssh/authorized_keys
chmod 640 ~/.ssh/authorized_keys

8. Format NameNode — fresh installation only
hdfs namenode -format
Do not repeat this on an existing HDFS setup containing data.

9. Start Hadoop
start-dfs.sh
jps
start-yarn.sh
jps

Expected processes:
NameNode, DataNode, SecondaryNameNode, ResourceManager, NodeManager.

10. Open web interfaces
HDFS: http://localhost:9870
YARN: http://localhost:8088

11. Stop Hadoop
stop-yarn.sh
stop-dfs.sh

12. WordCount program
The uploaded TXT gives Hadoop installation/configuration commands, but does not include a WordCount Java program or its compile/run commands in that section. This consolidated folder includes `code/WordCount.java` as a runnable lab example, with the basic compile, HDFS upload, execution and output commands in `code/WORDCOUNT_RUN.txt`.

Important source note: The TXT specifies replication factor 3. On a single-node lab, this can leave replicas under-replicated; if your instructor allows a single-node adjustment, use 1 instead. This note does not change the source's original value.
