CLOUD LAB CHEATSHEET — CONSOLIDATED PRACTICALS

This ZIP consolidates:
- The previous four apps (RESTful API, Firebase Hosting/Firestore, MongoDB CRUD, Dropbox API)
- Hadoop Word Count
- Spark Word Count
- OpenMP C++
- MPI Python
- CloudSim Basic Resource Allocation
- CloudAnalyst source link and source-limit notes

IMPORTANT SOURCE POLICY
For Hadoop, Spark, OpenMP, MPI, CloudSim and CloudAnalyst, the uploaded `labs 2.0(1).txt` is the basis.
Where the TXT has obvious shell-variable typos, the runnable command is corrected and the correction is explicitly noted.
The TXT does not contain CloudAnalyst installation/run steps or CloudSim build commands; those gaps are called out rather than presented as source-derived facts.

HOW TO USE
1. Extract the ZIP.
2. For Node/Firebase/MongoDB/Dropbox, read that folder's `steps.txt`.
3. For Hadoop/Spark/OpenMP/MPI/CloudSim/CloudAnalyst, read `installation_steps.txt`.
4. Keep credentials private; do not upload `.env` files or API tokens to public repositories.
5. The Hadoop, Spark, MPI and OpenMP commands are written for Ubuntu/Linux. They are not Windows CMD commands.
