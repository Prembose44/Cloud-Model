PRACTICAL: OPENMP C++ — BASED ON labs 2.0.txt

The TXT heading says "Openmpi", but the included code uses `#pragma omp parallel` and `omp_get_thread_num()`, which is OpenMP (not MPI).

Run in Ubuntu/Linux terminal.

1. Install libraries
sudo apt update
sudo apt install -y g++ libomp-dev

2. Create the C++ file
nano hello_omp.cpp

Copy the contents of code/hello_omp.cpp, then save:
Ctrl+O, Enter, Ctrl+X.

3. Compile
g++ -fopenmp hello_omp.cpp -o hello_omp

4. Run
./hello_omp

Expected: four lines, with thread IDs 0, 1, 2 and 3. The order may vary because threads execute concurrently.
